Privacy Policy

Schedule Me · Last updated 9 September 2026

Schedule Me is a small self-hosted appointment booking tool operated by Matt Clyde. It lets people book short appointments against a calendar that the organizer has connected. This policy describes what it collects, why, and who it is shared with.

Information we collect

From people booking an appointment, we collect only what the booking form asks for:

  • Name — so the organizer knows who the appointment is with.
  • Mobile phone number — used to confirm the booking, to send reminders and cancellation notices, and to sign you in when you want to view or cancel your appointment.

We do not ask for an email address, a postal address, a date of birth, or payment details. There are no advertising trackers or third-party analytics on this site.

How we sign you in

To view or cancel an appointment you request a one-time code, which we text to the phone number already on the booking. The code is short-lived and is the only credential involved — there are no passwords.

Google user data

This section describes how the application accesses, uses, stores, and shares Google user data.

Only the organizer connects a Google Account. People booking appointments never sign in with Google and no Google data of theirs is touched.

With the organizer's permission, the application uses the Google Calendar API on the organizer's connected calendar to:

  • Read events on that calendar, in order to work out which times are free and offer them as bookable slots.
  • Create an event when someone books an appointment.
  • Delete that event if the appointment is cancelled.

The application reads only whether a block of time is busy or free, together with the start and end times. It does not use the contents, titles, guests, or descriptions of the organizer's other calendar entries for any purpose, and it never copies them off the calendar.

We store the OAuth access and refresh tokens issued by Google so the application can keep reading the calendar without the organizer re-authorizing it each time. These tokens are stored on our own server and are not shared with anyone. The organizer can revoke them at any time (see Your choices below), and doing so immediately stops all access.

Limited Use disclosure

Schedule Me's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically, we do not use Google user data for advertising, we do not sell it, we do not transfer it to others except as needed to provide this service or as required by law, and we do not allow humans to read it except with the organizer's explicit permission, for security purposes, or where required by law.

Who we share information with

We do not sell personal information and we do not share it for advertising. Information is shared only with the service providers needed to make the application work:

  • Twilio — receives your phone number and message text in order to deliver SMS messages.
  • Google — receives the appointment time and the name on the booking, which are written into the organizer's calendar event.
  • Amazon Web Services — hosts the server and database.

We may also disclose information if we are legally required to.

Where information is kept

Data is stored in a private database on a server we operate in Amazon Web Services (US West). Access is restricted to the operator of the service.

How long we keep it

Appointments live on the organizer's Google Calendar and follow that calendar's own retention. Names, phone numbers, and a log of messages sent are kept while the booking service is in use so that people can look up their appointments and so we have a delivery record. You can ask us to delete yours at any time.

Your choices

  • Cancel an appointment — request a one-time code from the booking page and cancel it yourself.
  • Stop text messages — reply STOP to any message.
  • Organizers: disconnect Google — revoke this application's access at myaccount.google.com/permissions. Access ends immediately.

Children

This service is not directed at children under 13 and we do not knowingly collect their information.

Changes

If this policy changes we will update the date at the top of this page.
